# Nithin.EXE — 90s Vintage Portfolio

A deliberately retro personal portfolio built with plain HTML, CSS and JavaScript.

## Run

No build tools are required.

1. Open `index.html` directly in a browser, or
2. Run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — structure/content
- `style.css` — 90s Windows/GeoCities-inspired styling
- `script.js` — navigation highlighting, visitor counter, toast messages and CRT toggle

Content is based on Nithin Krishna's supplied resume.
